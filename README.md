# Modul 8 - Web Service Android (Ready)

Struktur:
- `server/` = Node.js + Express API
- `android-studio/MyWebServiceApp/` = Android Kotlin + Retrofit (XML)

## Quick Start
### 1) Server
```bash
cd server
npm install
npm start
```
Test:
- http://localhost:3000/
- http://localhost:3000/api/data

### 2) Android
Buka Android Studio -> Open -> `android-studio/MyWebServiceApp`

Run di emulator. Base URL default: `http://10.0.2.2:3000/`
